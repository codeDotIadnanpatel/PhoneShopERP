# Definition of Done

A feature is done only when:
- Acceptance criteria are met.
- Domain invariants and server-side authorization are implemented.
- Tenant and branch scoping are verified.
- Audit events are present for sensitive operations.
- Accounting and inventory effects are reconciled where applicable.
- Offline behaviour and sync conflict handling are implemented where promised.
- Error, retry, duplicate-submit and partial-failure cases are handled.
- Automated tests pass, including regression tests.
- UI is accessible, localized and responsive for its target surface.
- Telemetry and support diagnostics are adequate and redact sensitive values.
- API/schema documentation and migrations are reviewed.
- Traceability and implementation status are updated.
