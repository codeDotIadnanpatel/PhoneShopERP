# Warranty, Returns, Refunds and Exchanges

Support configurable manufacturer, retailer and repair warranties with start/end dates, coverage, exclusions, proof of purchase, serial/IMEI linkage and jurisdiction-specific consumer rights.

Return workflow:
1. Find original sale/receipt and item identity.
2. Verify return window, condition, warranty and policy.
3. Select return reason and disposition (restock, quarantine, supplier return, repair, write-off).
4. Calculate refund/exchange value and tax treatment.
5. Route approval based on amount and payment method.
6. Reverse or adjust inventory and create refund/payment liability.
7. Issue credit note/refund receipt and notify customer.

Support partial returns, exchange for another item, store credit and repair/replacement. Refund to original tender where required/possible; exceptions require reason and approval. Do not erase original sale. Warranty claim records must link to original asset and replacement asset.
