# Next.js Owner and Administration Portal

Responsive web application for owners, branch managers and accountants.

Sections: overview dashboard, branches, inventory, catalogue/pricing, purchasing, sales, customers, trade-ins, repairs, transfers, staff/commissions, accounting, reports, integrations, subscriptions and settings.

Requirements:
- Server-side authorization and tenant context; do not trust client-supplied tenant IDs.
- Clear branch/entity filters and timezone-aware date ranges.
- Drill from KPI to source documents and ledger details.
- Export controls and audit logs for sensitive reports.
- Accessible, responsive tables/forms and loading/error/empty states.
- Use typed API contracts and safe session handling.
- Long-running reports/imports show job state and notifications.
