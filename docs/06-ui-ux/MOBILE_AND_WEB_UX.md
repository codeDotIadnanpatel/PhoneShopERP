# Mobile and Web UX

Mobile staff tasks are step-based and one-handed: scan, capture, confirm, continue. Place primary actions in the thumb zone. Camera workflows should launch directly into a clear scanner/viewfinder with permission explanations and manual fallback.

Owner web portal prioritizes information hierarchy, branch/entity filters, drill-down and responsive layouts. Customer portal is minimal, privacy-first and task-oriented. All surfaces share terminology, status semantics and localization rules.
