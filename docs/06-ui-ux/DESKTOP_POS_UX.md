# Desktop POS UX

Single-window workspace with top context bar, left navigation, central work area and bottom operational status. Cashier lands directly on POS; technician on repair queue; owner/manager on dashboard based on role.

POS split pane: cart and scanned lines on left; totals and checkout actions on right. Keep scan input always discoverable and restore focus after actions. Parked carts are easy to save and recall. Use contextual drawers for trade-in and customer details rather than navigating away and losing cart state.

Show branch, register, cashier, shift, online/offline status, pending sync and last confirmed sync. Errors must explain what happened and the next safe action.
