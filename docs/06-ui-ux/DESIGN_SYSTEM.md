# UI Design System

## Principles
Fast, uncluttered, high-contrast and operationally clear. Use density appropriate to desktop retail while preserving legibility. Support dark and light themes; default theme may be configurable.

## Status semantics
Use consistent labels and colours for available, reserved, in transit, sold, repair, quarantined, offline, syncing, conflict, failed and approval-required states. Never communicate a critical state using colour alone.

## Components
Navigation shell, scan/search input, data grid, status badge, totals panel, step wizard, slide-out detail drawer, confirmation dialog, approval prompt, photo capture, timeline, audit viewer, notification centre and sync status.

## Accessibility
Keyboard navigation, visible focus, semantic labels, screen reader support, contrast, scalable typography and reduced motion. Avoid tiny controls and colour-only indicators.
