# Returns and Transfers

## Return
Locate sale → verify item and policy → inspect condition → approve → choose disposition → calculate refund/exchange/store credit → reverse payment and accounting effects → adjust inventory where appropriate → issue credit note and notify customer.

## Transfer
Create request → approve → scan serialized items/count bulk stock → dispatch and seal → mark in transit → receiving branch scans/counts → reconcile discrepancies → accept receipt → update location and accounting in-transit balances → close.
