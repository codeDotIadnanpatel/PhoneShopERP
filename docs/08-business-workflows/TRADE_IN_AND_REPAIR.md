# Trade-In and Repair Workflows

## Trade-in
Identify customer/device → capture required evidence → grade device → calculate offer → approval if needed → customer accepts → sign/consent → pay or issue store credit → create used-device asset → route to stock/quarantine/repair → post accounting.

## Repair
Customer/device intake → photos and damage mapping → estimate → customer approval → diagnosis → parts reservation/issue → repair work → quality check → ready notification → payment/collection → warranty activation → close ticket.
