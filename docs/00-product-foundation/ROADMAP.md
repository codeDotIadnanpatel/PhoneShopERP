# Product Roadmap

This is a sequencing proposal, not a promise of delivery dates.

## Foundation
Architecture boundaries, tenant security, identity, audit, localization framework, subscription entitlements, CI/CD, observability and test strategy.

## Release 1 — Retail core
Tenant onboarding; branches/registers; catalogue; IMEI and bulk inventory; suppliers; purchase orders and receiving; POS; parked carts; split payments; cash sessions; receipts; core stock accounting; essential GL; offline desktop operation; owner dashboard basics.

## Release 2 — Mobile retail differentiation
Trade-in/buyback; repair desk; parts-to-ticket consumption; warranty; returns/exchanges; branch transfers; stock counts; staff commissions; SMS/email notifications; Flutter staff app.

## Release 3 — Financial depth and customer experience
Full AP/AR workflows, bank reconciliation, budgets, fixed assets, period close, customer portal, loyalty, advanced analytics and scheduled reports.

## Release 4 — Global and enterprise expansion
Country compliance packs, additional payment/tax integrations, multi-entity consolidation, API marketplace, advanced controls, private/hybrid deployment options where commercially justified.

## Release gates
Each release requires data migration plan, security review, accounting validation, offline test coverage, support documentation, monitoring dashboards and rollback plan.

## Detailed engineering execution

This roadmap defines release-level product sequencing.
