# Observability and Support

Collect structured logs, metrics and traces with tenant-safe identifiers and correlation IDs. Avoid personal data, full IMEI, identity documents, credentials and payment secrets in logs.

Monitor API latency/error rates, database health, queue depth, sync backlog, conflict rates, failed notifications, payment webhook failures, subscription events and backup status.

Support tools should show tenant status, version, branch/register health, sync queue diagnostics and redacted error details. Access to tenant data for support requires authorization, purpose, expiry and audit. Publish service status and incident communication process.
